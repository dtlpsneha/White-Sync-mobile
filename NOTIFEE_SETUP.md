# Notifee Persistent Notification Setup

## What Changed

We've integrated Notifee to provide **TrueCaller-style persistent notifications** that stay on screen until the user dismisses them.

## Key Features

✅ **Persistent Popups** - Notifications stay on screen until user taps VIEW or DISMISS  
✅ **Works When Backgrounded** - Notifications appear even when app is closed  
✅ **Full-Screen Intent** - Can display as full-screen notification on lock screen  
✅ **Native Android Integration** - Uses native Android APIs for best behavior  
✅ **Minimal Expo Ejection** - Generated native code via `expo prebuild`, still uses Expo build system

## How It Works

### When App is Open
1. ERPNext sends push notification to Expo
2. Expo delivers to device via FCM
3. `NotificationPopup.tsx` captures it
4. **Notifee displays persistent popup** with VIEW/DISMISS buttons
5. User taps VIEW → navigates to quotation
6. User taps DISMISS → marks as read

### When App is Backgrounded/Closed
1. ERPNext sends push notification to Expo
2. Expo delivers to device via FCM
3. `BackgroundNotificationHandler.ts` (background task) runs
4. **Notifee displays persistent notification** in notification tray
5. Notification stays in tray until user dismisses it
6. User taps → app launches and navigates to quotation

## Notification UI

**Persistent Popup Features:**
- Large icon (notification bell)
- Title & body text
- ACTION BUTTONS:
  - **VIEW** (blue) - Opens the quotation
  - **DISMISS** (gray) - Marks as read, removes notification
- Big text style for better readability

## Permissions

The app now requests:
- `POST_NOTIFICATIONS` - Post notifications to notification tray
- `SYSTEM_ALERT_WINDOW` - Display overlay-style notifications
- `USE_FULL_SCREEN_INTENT` - Show full-screen notifications on lock screen

User is prompted to grant these when the notification first arrives.

## Troubleshooting

### Notifications not appearing?
- ✅ Check if notification permission is granted (Settings → Apps → White Sync → Notifications)
- ✅ Ensure app is on physical device or emulator with Google Play Services
- ✅ Check that ERPNext is sending notifications (check server logs)

### Popup disappears too quickly?
- Notifee should keep notifications persistent
- If disappearing, check Android system notification settings
- Some devices auto-dismiss notifications — check device settings

### "Display over other apps" permission?
- On first notification, app requests permission
- User may need to grant it in Settings → Apps → Special app access → Display over other apps
